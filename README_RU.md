# KDraw Russian — облачная сборка прототипа

## Что это
Это стартовый Android-проект для проверки облачной сборки APK через GitHub Actions.
Приложение открывает русский словарь интерфейса KDraw и страницу разрешения «поверх других окон».

**Важно:** это пока НЕ готовый автоматический русификатор. В этой версии нет захвата экрана,
OCR, распознавания китайских/английских надписей и наложения переводных плашек поверх KDraw.
Наличие разрешения Android само по себе не означает, что наложение уже реализовано.

## Как загрузить с телефона
1. Открой свой репозиторий GitHub `KDraw-Russian`.
2. Нажми **Add file** → **Upload files**.
3. Распакуй этот ZIP на телефоне. Загрузи ВСЁ содержимое папки проекта в корень репозитория,
   включая скрытую папку `.github`.
4. Нажми **Commit changes** внизу страницы.

Если мобильный сайт не показывает скрытую папку `.github`, используй GitHub в режиме
«Версия для ПК» в меню браузера либо загрузи файлы по отдельности через веб-интерфейс.

## Как получить APK
1. В репозитории открой вкладку **Actions**.
2. Выбери workflow **Build KDraw Russian prototype APK**.
3. Если сборка не запустилась сама, нажми **Run workflow** → **Run workflow**.
4. Дождись зелёной галочки.
5. Открой завершённый запуск и скачай артефакт `KDraw-Russian-prototype`.
6. Распакуй скачанный архив — внутри будет `app-debug.apk`.

Это тестовая debug-сборка. Android может показать предупреждение при установке APK из браузера.
Устанавливай только сборку из своего репозитория и проверяй источник файла.

## Следующая разработка
После проверки, что облачная сборка проходит, нужно реализовать:
- пользовательский запуск захвата экрана Android через системное подтверждение;
- OCR для текста интерфейса;
- сопоставление распознанных надписей со словарём;
- позиционирование русских надписей поверх оригинала с сохранением нажатий по исходным кнопкам;
- отдельную проверку совместимости с Android 16 и KDraw.
